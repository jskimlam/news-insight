# 케미칼 뉴스 인사이트

영문 석유화학 뉴스(플래츠 등)를 번역·요약해 신문 형식으로 보여주는 앱입니다. 하루에 한 판씩 쌓이고, 기사를 열면 요약, 전문 해석, 원문 대조를 볼 수 있습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체. GitHub Pages로 공개합니다. |
| `apps-script/Code.gs` | 구글시트와 화면을 잇는 API. 구글시트에 붙여넣어 사용합니다. (이 파일은 백업본) |
| 구글시트 `케미칼 뉴스 인사이트 DB` | 기사 원장. 월별 탭(`2026-11`)으로 쌓입니다. |

## 처음 한 번 설치하는 순서

### 1. Apps Script 붙여넣기
1. 구글시트를 열고 `확장 프로그램 > Apps Script`를 누릅니다.
2. 기본으로 있는 코드를 모두 지우고 `apps-script/Code.gs` 내용을 통째로 붙여넣은 뒤 저장(Ctrl+S)합니다.
3. 위쪽 함수 선택 칸에서 `checkSetup`을 고르고 `실행`을 누릅니다. 권한 승인 창이 뜨면 본인 계정으로 승인합니다.
   (`확인되지 않은 앱` 경고가 나오면 `고급 > 프로젝트 이름(안전하지 않음)으로 이동`을 누릅니다.)
4. 아래 `실행 로그`에 월 탭 목록과 날짜 목록이 나오면 정상입니다.

### 2. 등록 키 정하기
1. 왼쪽 톱니바퀴(프로젝트 설정)를 누릅니다.
2. 맨 아래 `스크립트 속성 > 스크립트 속성 추가`를 누릅니다.
3. 속성에 `REGISTER_KEY`, 값에 원하는 비밀번호를 입력하고 저장합니다.

### 3. 웹앱으로 배포
1. 오른쪽 위 `배포 > 새 배포`를 누릅니다.
2. 톱니바퀴에서 유형을 `웹 앱`으로 고릅니다.
3. 실행 주체는 `나`, 액세스 권한은 `모든 사용자`로 설정하고 `배포`를 누릅니다.
4. 나오는 `웹 앱 URL`(https://script.google.com/macros/s/.../exec)을 복사합니다.
   `?action=ping`을 뒤에 붙여 브라우저에서 열었을 때 `"ok":true`가 보이면 정상입니다.

### 4. 화면에 주소 넣기
`index.html`을 열어 아래 줄의 주소를 3번에서 복사한 URL로 바꿉니다.

```js
const API_URL = 'PASTE_YOUR_WEB_APP_URL_HERE';
```

### 5. GitHub Pages로 공개
1. 저장소에 `index.html`, `apps-script/Code.gs`, `README.md`를 올립니다.
2. 저장소의 `Settings > Pages`에서 Branch를 `main`, 폴더를 `/ (root)`로 두고 저장합니다.
3. 몇 분 뒤 `https://계정명.github.io/저장소명/` 주소로 열립니다.

## 매일 쓰는 방법

1. 화면 오른쪽 위 `새 뉴스 등록`을 누릅니다.
2. `Claude용 요청문 복사`를 누르고, Claude 대화창에 붙여넣은 뒤 맨 아래에 영어 원문을 넣어 보냅니다.
3. Claude 답변 전체를 `Claude 답변` 칸에 붙여넣고 `아래 칸 자동 채우기`를 누릅니다.
4. 영문 제목, 원문 URL, 영어 원문을 채우고 등록 키를 입력한 뒤 `저장하기`를 누릅니다.
5. 같은 URL이나 같은 제목의 기사는 중복 경고가 뜹니다. 정말 다른 기사면 `그래도 저장`을 누릅니다.

## 시트를 직접 고쳤을 때

시트에서 기사를 직접 수정하거나 삭제하면 화면에는 최대 10분(오늘 호) 또는 6시간(지난 호) 뒤에 반영됩니다. 바로 반영하려면 시트 메뉴 `뉴스 앱 > 캐시 비우기`를 실행하고, 화면에서 `↻ 새로고침`을 누릅니다.

## 시트 규칙

- 탭 이름은 `YYYY-MM` 형식입니다. 새 달의 첫 기사를 등록하면 자동으로 만들어집니다.
- A열부터 P열까지의 순서와 머리글은 바꾸지 마세요.
- A~L열은 1면에 쓰는 가벼운 정보이고, M~P열은 기사를 열 때만 읽는 전문 해석과 영어 원문입니다.
- 셀 하나에는 4만 5천 자까지 저장하고, 넘으면 `이어서` 열에 나누어 저장합니다. 해석과 원문 각각 총 9만 자까지 저장할 수 있습니다.
- 출처가 `샘플`인 행은 화면 확인용입니다. 필요 없으면 행을 삭제하세요.

## 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 화면에 `샘플 모드`라고 뜬다 | `index.html`의 `API_URL`에 웹앱 URL을 넣었는지 확인합니다. |
| `서버에 연결할 수 없습니다` | 배포 설정의 액세스 권한이 `모든 사용자`인지, URL 끝이 `/exec`인지 확인합니다. |
| 코드를 고쳤는데 반영이 안 된다 | Apps Script에서 `배포 > 배포 관리 > 수정 > 버전: 새 버전`으로 다시 배포합니다. URL은 그대로입니다. |
| `등록 키가 설정되지 않았습니다` | 스크립트 속성에 `REGISTER_KEY`를 추가했는지 확인합니다. |
| 저장은 됐는데 화면에 안 보인다 | `↻ 새로고침`을 누르고, 그래도 안 되면 시트 메뉴 `뉴스 앱 > 캐시 비우기`를 실행합니다. |
